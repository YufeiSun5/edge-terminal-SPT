# 主服务器收口验收矩阵

最后更新：2026-06-04

维护责任：`review-ai` / 后续验证按 `test-ai`、缺陷修复按 `backend-ai`、页面固化按 `frontend-ai`

本文档是 EB-067 的 contract/readiness matrix。目的不是扩展主服务器功能，而是把当前主服务器能力收敛成可重复验收标准，用于后续评估 EB-059、EB-055、EB-056 是否能关闭或拆分。

## 1. 收口原则

1. 主服务器是多边缘聚合桥、统一登录入口、统一执行入口和历史/报表查询副本；边缘端仍是现场执行权威。
2. 主服务器读取三类数据源：同步库真实表、边缘端 service-token 实时/运行态镜像、主服务器自有报表表。
3. 主服务器不得写同步来的边缘业务表；写现场动作必须回到边缘端 `/api/v1/edge-control/*`。
4. 前端 `main_server` 模式业务 API 和 WS 只连主服务器 `19080`，不得直连边缘端 `18080/18081`。
5. EB-067 不以 MQTT/KIO 在线采集、物理变量下设或压力测试作为前置；这些属于后续现场链路验证。

## 3. Edge 路由规则

主服务器所有涉及边缘运行态、控制或项目作用域的接口必须遵守以下解析顺序：

```text
显式 edge_instance_id query/header
  -> HTTP envelope 顶层 edge_instance_id/project_id/task_id/var_id
  -> nested payload.project_id/task_id/var_id/project_code + var_name
  -> 同步库 sys_projects/sys_detection_tasks/sys_tags 解析 edge_instance_id
  -> 单边缘兼容 fallback
```

硬性规则：

- 显式 edge 与业务目标解析结果不一致，必须硬失败，不得默认发到 edge-1。
- 多边缘且无法解析目标，必须返回 `409 *_unresolved` 或 `*_ambiguous`。
- 浏览器不得直连边缘端；所有 service token 只保存在主服务器后端配置/环境中。
- 大 64 位变量 ID 必须保留 `var_id_text`，前端和报表请求优先用字符串。

## 5. EB-059/055/056 关闭判断

### EB-059 主服务器后端雏形

可关闭条件：

- Contract matrix 中同步库只读、service-token mirror、edge-control、report worker、station view 路径均有真实单元/集成或 smoke 证据。
- 一主二边缘非压测 smoke 通过，且 edge-2 不可达负向通过。
- 未实现的读接口明确返回 `501 main_server_query_route_not_implemented`，写代理明确返回 `501 edge_control_required`。

不能阻塞关闭的后续项：

- MQTT/KIO 在线采集压测。
- 客户模板公式单元格映射。
- 拖拽模板设计器和跨边缘聚合大屏。

### EB-055 主服务器拆分和一套前端

可关闭条件：

- `VITE_APP_ROLE=main_server` 页面 smoke 固化为可重复命令。
- 页面业务 API/WS 全部走 `19080`，无浏览器直连 `18080/18081`。
- 主服务器模式下隐藏或降级 edge-only sidecar、KIO、网关写入入口；需要的读/诊断接口均由主服务器实现或返回明确诊断。

保留后续：

- 页面体验打磨。
- 更多业务流 smoke。
- 彻底删除前端历史 `device_*` 兼容别名。

### EB-056 边缘端 HTTP 主服务器控制通道

可关闭条件：

- service token、scope、CIDR、幂等、操作者映射、审计、命令生命周期均有测试。
- 主服务器 HTTP 和 WS command 都能自动路由到正确 edge。
- start/stop/pause/resume/write_variable/report_request/update_limits/refresh_features/mute_alarms 至少有非破坏 smoke 或明确接口证据。

保留后续：

- 报警静音持久化字段。
- 真实物理变量 KIO 下设和回读确认。
- 更高强度的现场网络异常、重试和压测。

## 6. 2026-06-04 关闭评估

`review-ai` 评估结论：在“主服务器收口验收与非压测一主二边缘链路”范围内，EB-059、EB-055、EB-056 可以关闭；未完成内容不再作为这三个 EB 的开放项保留，应拆为更小后续事项。

关闭依据：

- EB-059 主服务器后端雏形：同步库只读、service-token realtime/runtime/metadata mirror、HTTP edge-control、WS facade、report readiness/job、station view 同名只读/reload 均已有单元、集成或 smoke 证据；一主二边缘 contract smoke `desktop/output/playwright/eb067-main-server-contract-smoke-20260604113207.json` 通过；edge-2 不可达负向 `desktop/output/playwright/eb067-edge2-unavailable-negative-20260604220309.json` 通过。
- EB-055 主服务器拆分和一套前端：新增可重复命令 `desktop npm run smoke:main-server`，证据 `desktop/output/playwright/main-server-regression-20260604140650.json` 证明 9 个主要页面业务 API/WS 全部走 `19080`，浏览器不直连 `18080/18081`，无 mock/fallback 计为通过。
- EB-056 边缘端 HTTP 主服务器控制通道：service token、scope、CIDR/allowed list、幂等命令生命周期、操作者注入、审计和 edge-control envelope 已由单元/集成与真实 command smoke 覆盖；HTTP 和 WS command 都能按 payload 自动路由到正确 edge；edge-2 down 时 edge-2 控制返回 `502` 且 edge-1 不受影响。

关闭后的后续项：

- 真实现场 MQTT/KIO 在线采集、物理 KIO 下设和回读确认。
- 报警静音持久化字段与更多报警体验。
- 客户报表模板公式单元格映射和拖拽式模板设计器。
- 更多前端页面体验打磨、更多业务流 E2E。
- 多主冲突合并、跨边缘聚合大屏和现场压测。
