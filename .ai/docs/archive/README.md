# Archive

## 用途

本目录保存失效规范、旧阶段总结、闭合看板记录和不再作为当前事实来源的历史材料。

实时交互看板在根目录 `AI_BOARD.md`；本目录只用于查历史，不承载当前 open/blocked 工作。

## 历史索引

- `2026-05-31-ai-board-closed-records.md`：从 `AI_BOARD.md` 迁出的闭合 Active Board 记录和闭合 Activity Log。

新增归档文件后必须更新本索引，写清文件保存的范围和来源。AI 需要翻历史时，先看根目录 `AI_BOARD.md` 的当前 open/blocked 项，再按本索引进入对应归档文件；不要在归档目录寻找当前任务。

## 命名规范

- `YYYY-MM-DD-topic.md`
- `phase-YYYY-MM-DD.md`

## 什么时候创建新文件

- 根目录 `AI_BOARD.md` 活动日志或 closed 项过长，需要迁移闭合内容。
- 稳定文档被新设计替代，但仍需保留追溯。
- 闭合事项没有合适的稳定文档承接，但仍需要保留结论、证据或背景。

## 什么时候不要创建新文件

- 不要放当前 open/blocked 项。
- 不要放仍在使用的契约正文。
