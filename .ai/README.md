# .ai

本目录是 AI 协作文档母本。跨编辑器适配层只能链接或摘要这里的内容，不复制完整规范。

## 目录

| 目录 | 用途 |
| --- | --- |
| `instructions/` | 分领域编码和协作规范。 |
| `docs/` | 稳定设计文档、闭合记录、阶段总结和归档材料。 |
| `skills/` | 可复用的项目特定操作技能。 |
| `agents/` | 自定义 AI Agent 定义。 |
| `prompts/` | 常用任务 Prompt 模板。 |

## 创建规则

需要跨编辑器长期复用的规范先写入 `.ai/`。临时讨论、open/blocked 工作项、协作状态只写根目录 `AI_BOARD.md`。

不要在本目录下创建第二个活跃看板。
